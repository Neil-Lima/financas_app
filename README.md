## 📋 Sobre o Projeto

Desenvolvi este aplicativo de finanças pessoais para ajudar no controle e gerenciamento financeiro do dia a dia. Com uma interface intuitiva e recursos abrangentes, o Finanças App permite acompanhar despesas, receitas, investimentos e muito mais, tudo em um só lugar.

### ✨ Recursos Principais

- **Dashboard Interativo**: Visão geral das finanças com gráficos e estatísticas
- **Controle de Transações**: Registro e categorização de receitas e despesas
- **Gestão de Contas**: Acompanhamento de múltiplas contas e cartões
- **Orçamentos Mensais**: Definição e acompanhamento de limites por categoria
- **Metas Financeiras**: Configuração de objetivos e acompanhamento de progresso
- **Controle de Parcelamentos**: Gestão de compras parceladas
- **Financiamentos**: Acompanhamento de empréstimos e financiamentos
- **Gestão de Estoque**: Controle básico de itens e produtos
- **Relatórios Exportáveis**: Geração de PDF e CSV para análises detalhadas

## 📦 Instalação e Configuração

### Pré-requisitos
- Node.js (versão 14 ou superior)
- MongoDB (local ou atlas)
- npm ou yarn

### Configuração do Backend
```bash
# Clone o repositório
git clone https://github.com/seu-usuario/financas_app.git
cd financas_app/backend

# Instale as dependências
npm install

# Configure as variáveis de ambiente
# Crie um arquivo .env com base no .env.example

# Inicie o servidor
npm run dev
```

### Configuração do Frontend
```bash
# Na pasta raiz do projeto
cd frontend

# Instale as dependências
npm install

# Inicie o aplicativo
npm start
```

O frontend estará disponível em `http://localhost:3000` e o backend em `http://localhost:5006`

## 📊 Arquitetura

O projeto segue uma arquitetura moderna de aplicação web:

- **Frontend**: SPA (Single Page Application) em React
- **Backend**: API RESTful em Node.js/Express
- **Banco de Dados**: MongoDB com Mongoose
- **Autenticação**: JWT com estratégias Passport
- **Comunicação em tempo real**: Socket.io
